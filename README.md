# chemistry-naming-skill

人教版九年级化学（2024版）备课资料标准化命名 Skill for [opencode](https://opencode.ai)。

## 功能

- 完整教材目录（绪论~第十一单元，含全部课题、实验活动、跨学科实践活动）
- 17种标准文件类型标识（教案、课件、学历案、单元检测、知识清单及母题等）
- 4种命名方案（简洁数字式、完整数字式、课题序号式、纯知识清单式）
- 五步工作流程（分析→识别→提供方案→执行→验证）
- 资源视频命名规则

## 使用

将 chemistry-naming.skill 文件导入 opencode，或在 .opencode/skills/ 目录下放置 chemistry-naming/SKILL.md。

## 安装

`ash
# 方式1：直接下载 skill 文件
curl -LO https://raw.githubusercontent.com/adidalin/chemistry-naming-skill/main/chemistry-naming.skill

# 方式2：克隆仓库到 opencode skills 目录
git clone https://github.com/adidalin/chemistry-naming-skill.git
`

## 为什么需要这个 Skill？

化学教师在日常备课中会积累大量文件：教案、课件、学历案、作业、检测卷、答案、教学视频……随着时间推移，文件名越来越混乱：

```
第四单元_4.1水资源及其利用_水资源及其利用_教案.doc
第七单元 燃料的燃烧和利用复习课.pptx
十单元复习教案.doc
第第十一单元_复习课_复习学历案.docx
媒体1.mp4
6.第五单元 主题综合实践作业.doc
```

这个 Skill 的作用就是：**知道教材长什么样，知道文件该怎么命名，帮你在几秒内理清所有文件**。

它内置了 2024 版人教版九年级化学全册的教材目录，并提供多种命名方案供选择，无论是教学新手还是经验丰富的教师都能快速上手。

## 命名方案

### 方案A：简洁数字式

排序友好，适合专题资料和日常浏览。

```
文件夹：1单元_走进化学世界/
课时：  1.1物质的变化和性质/
文件：  1.1物质的变化和性质_教案.doc
复习：  第一单元_复习课_教案.docx
检测：  第一单元_单元检测.docx
答案：  第一单元_答案.docx
综合：  第一单元_主题综合实践作业.docx
```

### 方案B：完整数字式

序号两位对齐（01-11），适合正式备课目录。

```
文件夹：01_第一单元/
        02_第二单元/
        00_绪论/
课时：  1.1物质的变化和性质/
文件：  1.1物质的变化和性质_教案.doc
备课：  第一单元_单元备课.doc
```

### 方案C：课题序号式

严格按教材课题编号，与课本页码对应。

```
文件夹：01_第一单元_走进化学世界/
课时：  课题1_物质的变化和性质/
        课题2_化学实验与科学探究/
        实验活动1_氧气的实验室制取与性质/
        跨学科实践1_微型空气质量检测站的组装与使用/
文件：  课题1_物质的变化和性质_教案.doc
        课题2.1_化学实验与科学探究_学历案.docx
```

### 方案D：纯知识清单式

极简风格，适合知识梳理和考前复习。

```
文件夹：1单元_走进化学世界/
文件：  第一单元_知识清单及母题.docx
        第一单元_答案.docx
```

## 命名规则速查

### 分隔符

统一使用**下划线 `_`**，禁止空格、`+`、`《》`、`（` 等符号。

### 课时编号

| 层级 | 格式 | 示例 |
|------|------|------|
| 主课题 | `{单元号}.{课题号}{课题名}` | `1.1物质的变化和性质` |
| 子课题 | `{单元号}.{课题号}.{子序号}{子课题名}` | `1.2.1化学实验与科学探究` |
| 拓展主题 | `{课题号}{主课题}_{拓展主题}` | `8.2高铁建设中金属材料的获取` |
| 实验活动 | `实验活动{编号}` | `实验活动1` |
| 跨学科实践 | `跨学科实践{编号}` | `跨学科实践1` |
| 绪论 | `绪论` | `绪论_教案.doc` |

### 统一用词

| 不规范 | 标准 |
|--------|------|
| `学案` | `学历案` |
| `单元测试` / `检测卷` | `单元检测` |
| `题库答案` / `母题答案` | `答案` |
| `知识清单+母题` / `知识基础过关清单` | `知识清单及母题` |

### 常见错误修正

| 错误 | 正确 |
|------|------|
| `母体过关` | `母题` |
| `第第十一单元` | `第十一单元` |
| `八单元` | `第八单元` |

## 工作流程

### 步骤1：分析
读取目标目录，了解文件/文件夹现状。

### 步骤2：识别
找出命名不一致、格式不规范、结构混乱、无意义命名等问题。

### 步骤3：提供方案
展示可行命名方案（A/B/C/D），由用户选择。

### 步骤4：执行
创建文件夹、移动文件、重命名、标记废弃文件夹。

### 步骤5：验证
列出最终结构，确认无文件丢失或重复。

- "按教材目录创建文件夹"
- "这个文件夹命名太乱了"

## 常见问题

**Q：会删除文件吗？** 不会。只重命名和移动，不删除。旧文件夹标记 `[废]` 前缀。

**Q：支持哪些教材？** 人教版九年级化学（2024版）全册。

**Q：可以自定义方案吗？** 可以。直接说明需求即可定制。

**Q：扩展名会变吗？** 不会。`.doc` 保持 `.doc`。
